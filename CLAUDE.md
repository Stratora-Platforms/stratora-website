## Claude Code notes

- When you claim an issue, set the project's Agent field to "Claude Code".
- This repo is public. Before any commit, PR, issue or comment, check the text
  against the PUBLIC REPO RULES in AGENTS.md.
- To look at a change, run `npm run dev` (or `npm run build` then
  `npx vite preview`) and check it in a browser at phone and desktop widths.
- Board moves, comments and new issues need no halt; diff, commit and push do
  (unless the owner approved the workflow), and merging or pushing to `main`
  always needs the owner (it deploys the live site). See "Approval" in
  AGENTS.md.
